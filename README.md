# Tempy

Small rust program to convert temperature values from fahrenheit to celsius and
vice versa.

## Why?
This was built to get some practice with concepts from chapter 3 of the rust book.

## Prerequisites
[Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html)

## Compatibility
It's rust so it should just work on any of the big three? There's some docs on
Windows exceptions I ain't quite read yet...

## Usage
Download the repository:

```sh
git clone git@github.com/fuguesoft/tempy
```

Run the program from within the project root:

```sh
cd /path/to/tempy
cargo run
```
